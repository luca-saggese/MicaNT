- Liberation fonts: Copyright Red Hat, Inc. and contributors; see LICENSE-Liberation.txt. TTFs are from the [official Liberation Fonts 2.1.5 release](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5).
- Carlito: Copyright The Carlito Project Authors; SIL Open Font License 1.1. All four styles were built from the [official googlefonts/carlito source](https://github.com/googlefonts/carlito) using fontmake 3.12.2.
- DejaVu Sans: see LICENSE-DejaVu.txt. TTFs are from the [official DejaVu Fonts 2.37 release](https://dejavu-fonts.github.io/Download.html). Regular, Bold, Italic and Bold Italic are included for Unicode fallback.
